# Championnat MakaCorp

Site statique du classement rallye communautaire.

Publier avec GitHub Pages :

1. Creer un depot GitHub public.
2. Envoyer tous les fichiers de ce dossier a la racine du depot.
3. Aller dans Settings > Pages.
4. Dans Build and deployment, choisir Deploy from a branch.
5. Choisir la branche main et le dossier /root.
6. Attendre que GitHub donne le lien public.

La page d'accueil est `index.html`.
